# Ai-Blog-Generator

Automated blog generator for **[Protection Tax](https://protectiontax.com)** — a
tax resolution company. It rotates through a list of tax-resolution topics,
writes a full blog post with **Google Gemini**, generates a featured image with
**Hugging Face**, and publishes it to WordPress via the REST API — on a
consistent, cron-based schedule.

## How it works

1. **Topic rotation** — `topics.py` holds an ordered list of topics. The next
   topic is served in rotation and the position is saved to `state/topic_state.json`,
   so the rotation continues across restarts and wraps around at the end.
2. **Content** — `content_generator.py` prompts Gemini for an SEO-friendly post
   (title, excerpt, HTML body, tags, and an image prompt) as structured JSON.
3. **Image** — `image_generator.py` turns the image prompt into a featured image
   using the Hugging Face Inference API (default model: FLUX.1-schnell).
4. **Publish** — `wordpress_client.py` uploads the image to the media library and
   creates the post (title, body, excerpt, tags, featured image) via the
   WordPress REST API.
5. **Schedule** — `main.py schedule` runs the whole pipeline on a cron schedule
   using APScheduler.

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env   # then fill in your keys
```

### Required credentials (`.env`)

| Variable | What it is |
| --- | --- |
| `GEMINI_API_KEY` | Google AI Studio API key for Gemini |
| `HF_API_TOKEN` | Hugging Face access token (read scope) |
| `WP_BASE_URL` | Your WordPress site, e.g. `https://protectiontax.com` |
| `WP_USERNAME` | WordPress username |
| `WP_APP_PASSWORD` | A WordPress **Application Password** (Users → Profile → Application Passwords) |

Optional: `GEMINI_MODEL`, `HF_IMAGE_MODEL`, `WP_POST_STATUS` (`draft`/`publish`/…),
`WP_CATEGORY_IDS`, `POST_CRON`, `SCHEDULE_TIMEZONE`. See `.env.example` for all
options and defaults.

> **Tip:** start with `WP_POST_STATUS=draft` so you can review each post in the
> WordPress dashboard before it goes live. Switch to `publish` once you're happy.

## Usage

```bash
# List the topic rotation and see what's next
python main.py topics

# Generate & publish one post now (advances the rotation)
python main.py run

# Generate a post for a specific topic (does not advance the rotation)
python main.py run --topic "How to stop an IRS wage garnishment"

# Run continuously on the schedule (default: Mon & Thu 9am, America/Los_Angeles)
python main.py schedule
```

### Running the schedule in production

`python main.py schedule` is a long-running process. Keep it alive with a
process manager such as `systemd`, `supervisor`, Docker, or a `cron`/container
host. The schedule itself is controlled by `POST_CRON` (standard 5-field cron)
and `SCHEDULE_TIMEZONE`.

## Customizing topics

Edit the `TOPICS` list in `topics.py`. Add, remove, or reorder freely — new
topics appended to the end are picked up automatically on the next rotation.

## Notes

- Content is generated by an LLM; **review posts before publishing** (keep
  `WP_POST_STATUS=draft` while you build trust in the output).
- The generator is instructed to avoid fabricating statistics, dollar figures,
  or specific IRS rules, and to include a "general information, not tax/legal
  advice" disclaimer — but always review for accuracy.
- If image generation fails, the post is still published without a featured image.
